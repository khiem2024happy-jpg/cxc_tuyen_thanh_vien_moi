# Cảm Xúc Club — Tuyển Thành Viên CLB Âm Nhạc Hạ Long

Trang Landing Page tuyển thành viên chính thức của CLB Âm Nhạc Cảm Xúc tại TP. Hạ Long.

## 🚀 Hướng dẫn Đẩy lên GitHub & Deploy Vercel

### Cách 1: Đẩy code bằng Git CLI
```bash
git init
git add .
git commit -m "Initial commit for Cam Xuc Club landing page"
git branch -M main
git remote add origin https://github.com/<username>/<repo-name>.git
git push -u origin main
```
Sau đó truy cập [Vercel](https://vercel.com), bấm **Add New Project** -> Chọn repository vừa tạo và bấm **Deploy**.

### Cách 2: Kéo thả trực tiếp lên GitHub
1. Tạo một repository mới trên GitHub.
2. Tải toàn bộ file trong thư mục này lên GitHub thông qua nút **Upload files**.
3. Vào Vercel Import repo đó, Vercel sẽ tự động nhận diện `index.html` và deploy chỉ sau 10 giây.
